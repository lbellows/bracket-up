# `com.bracketup.app.yml`

This is **not** a build recipe. It is the app-level listing metadata for the
self-hosted F-Droid repo at <https://github.com/lbellows/fdroid>.

`fdroid update` takes the description, icon and screenshots from the fastlane
tree (`fastlane/metadata/android/`), but it reads `License`, `Categories`,
`SourceCode`, `IssueTracker` and the app name from `metadata/<appid>.yml`. That
file is generated by the publish workflow in the `fdroid` repo, which clones this
repo and runs `scripts/app_metadata.py` against the path named by the `recipe`
key for this app in its `apps.json`.

So:

- **Do not rename or move this file** without updating `apps.json` in the
  `lbellows/fdroid` repo. If the path stops resolving, the publish job logs a
  warning and BracketUp lists with licence "Unknown", no category and no source
  link.
- Keep it to app-level fields only. Anything describing *how* to build is
  ignored by the publisher and does not belong here.
- `AllowedAPKSigningKeys` is deliberately absent — the publisher takes the
  signing key from `apps.json` instead.

Version fields are a convenience for readers; the repo index derives the real
versions from the APKs it publishes.
